# Constituição do Projeto

1. Use Python 3.14+ e pytest para todos os testes.
2. Mantenha o código simples e sem dependências externas desnecessárias.
3. Nenhum código entra sem cláusula EARS correspondente em `specs/`.
4. Toda mudança de regra de negócio começa na spec; spec, testes e código mudam no mesmo commit.
5. O código deve referenciar as cláusulas que implementa (ex.: `REQ-01`).
